# Languages — личная база изучения языков

Словари, учебный прогресс и планы будущих уроков по японскому, китайскому и древнегреческому языкам.

## Структура

| Язык | Слова | Иероглифы / алфавит | Прогресс | Будущие уроки |
|---|---|---|---|---|
| Японский | `japanese/words.json` | `japanese/kanji.json` | `japanese/progress.json` | `japanese/learning_queue.json` |
| Китайский | `chinese/words.json` | `chinese/hanzi.json` | `chinese/progress.json` | `chinese/learning_queue.json` |
| Древнегреческий | `greek/words.json` | `greek/alphabet.json` | `greek/progress.json` | `greek/learning_queue.json` |

## Для чего нужен learning_queue.json

**У каждого языка свой отдельный файл `learning_queue.json`.** Это очередь тем, которые пользователь хочет изучить в ближайшем будущем. Она нужна, чтобы при просьбе «Давай новый урок японского/китайского/древнегреческого» ассистент или учебное приложение могло выбрать подходящую тему из соответствующей папки, а не придумывать программу с нуля.

### Инструкция для ассистента и приложения

1. Определить запрошенный язык и прочитать только его `<language>/learning_queue.json`.
2. Выбирать темы со статусом `planned`, сначала с приоритетом `high`, учитывая `prerequisite_ids` и уже изученное в `progress.json`.
3. Составить короткий урок по `title` и `objectives` с учётом словаря и прогресса языка. Если запрос общий, предложить наиболее подходящую тему.
4. После занятия по подтверждённым результатам обновить `progress.json`, словарь и, при необходимости, статус темы: `planned` → `in_progress` → `completed`. Не считать тему освоенной без подтверждения пользователя.
5. Если пользователь просит запомнить тему на будущее, добавить её в файл соответствующего языка с уникальным `id`, `title`, `priority`, `status: "planned"` и `objectives`. Не помещать темы разных языков в один файл.
6. Сохранить изменения коммитом в GitHub. Само наличие файла не запускает уроки автоматически: ассистент или приложение должно прочитать его при запросе.

### Значения статусов

- `planned` — запланировано.
- `in_progress` — изучается.
- `completed` — освоено и подтверждено.
- `paused` — отложено.

## Принципы учёта знаний

Для иероглифов значение, чтение и письмо учитываются независимо. Упоминание знака в упражнениях не доказывает освоения. Содержимое словарей — начальная база, а не полный перечень изученного.
