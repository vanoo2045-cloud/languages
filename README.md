# Languages — личная база изучения языков

Словари и учебный прогресс по японскому, китайскому и греческому языкам.

- `japanese/words.json` — японские слова и выражения.
- `japanese/kanji.json` — кандзи: значение отдельно от чтений.
- `japanese/progress.json` — история и состояние изучения.
- `chinese/README.md` — место для китайского словаря.
- `greek/README.md` — место для греческого словаря.

Статусы: `learned_meaning` — узнаётся значение; `reading_confirmed` — подтверждено чтение; `practiced_writing` — практиковалось письмо. Эти признаки независимы.

Данные основаны на ранее обсуждённых упражнениях; неизвестные чтения не помечены как выученные.
