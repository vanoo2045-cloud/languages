# Древнегреческий язык

Для чтения Первого послания апостола Павла к Коринфянам изучаем новозаветный койне. В курс также входят молитвы и византийская гимнография.

## Слова, которые я считал выученными

В [`thought_i_knew.json`](thought_i_knew.json) попадают слова, которые пользователь считал знакомыми, но при проверке перевёл неверно или не смог перевести. Записывать греческую форму в `greece`, верный перевод в `word`, а в `notes` — что именно вызвало затруднение. Если слово встретилось в тексте, указать источник в `source`. Использовать этот список для повторения.
